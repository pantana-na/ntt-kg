# F-34 — Fuel Pool Postfilter

## Function

Fuel Pool Postfilter installed downstream of Demineralizer DM-8 to capture resin fines, particulates, and resin fragments, preventing radioactive resin carryover into the Spent Fuel Pool. Effluent discharges through a 4" return header terminating 11 ft above spent fuel assemblies.

## Hazards & Safeguards

- Resin fine breakthrough / element blinding: Monitored across filter shell by PDIS-2623; high differential pressure indicates resin migration from DM-8 or filter clogging.
- Filter venting: Top vent V30 routes through common sight glass FG-2612 to ensure complete liquid priming and de-aeration before operation.
- Siphon break / pool drainage prevention: Return line check valve 1-SF-V34 and discharge elevation (+11 ft above fuel assemblies per Note 6) prevent inadvertent gravity siphoning of pool water.
